# Changelog - Advanced Sales Dashboard (ts_sales_dashboard)

## [19.0.2.2.0] - 2026-08-28
### Added
- Customer filter: a search-as-you-type (`res.partner` `name_search`) picker in
  the dashboard header scopes every card, KPI, comparison delta and
  drill-through domain to the chosen client. `get_dashboard_data` gained a
  fifth `partner_id` argument and returns `partner_id` / `partner_name` /
  `hidden_when_customer`. While a customer is selected, the cross-customer
  cards (Customer Insights, New vs Repeat gauges, Quotation Conversion,
  Geography, Team Achievement, Top 5 Customers, Best/Red Client) are hidden.
- Listing page (`static/description/index.html`) updated for the company and
  per-customer filters (intro, Available Filters box, Key Features grid,
  "Go From Insight to Action" section).

## [19.0.2.1.0] - 2026-08-28
### Added
- Company filter: a dropdown in the dashboard header (shown only when the user
  belongs to more than one company) scopes every card's query, KPI, comparison
  delta and drill-through domain to the selected company, or aggregates all of
  the user's companies when set to "All Companies". `get_dashboard_data` gained
  a fourth `company_id` argument and now returns `companies` / `company_id`;
  the currency block follows the selected company.

## [19.0.2.0.0] - 2026-08-25
### Changed
- **Breaking:** renamed the module's technical name from `pr_sales_dashboard`
  to `ts_sales_dashboard` (folder, manifest, model `_name`
  `pr.sales.dashboard` → `ts.sales.dashboard`, action/menu/template XML IDs,
  JS action name, CSS classes, and both translation files). Deployments on
  the old technical name must uninstall `pr_sales_dashboard` and install
  `ts_sales_dashboard`; there is no in-place upgrade path since Odoo treats
  this as a different module.
- Manifest summary now notes the dashboard works on both Odoo Community and
  Enterprise (it only depends on `sale`).

### Added
- Listing page (`static/description/index.html`) gained a "See It In Action"
  screenshot gallery (dashboard overview, date-range filter, period
  comparison, lost pipeline & quotation aging) plus Dashboard Coverage and
  Key Features entries for Invoicing Status, Lost Pipeline, Open Quotation
  Aging, and period-over-period comparison deltas.

## [19.0.1.0.0] - 2026-08-25
### Added
- Initial release. Executive sales dashboard with revenue, orders, customers,
  products, geography, and team KPIs, built on top of `sale`.
- Average Order Value KPI, alongside the existing top-line metrics.
- Global date-range filter (All Time / This Year / Last Year / This Quarter /
  Last N Months / Custom Range) that scopes every card's query and
  drill-through domain, independent of the Monthly Trends chart's own
  lookback toggle.
- Period-over-period comparison deltas (▲/▼ %) on the top KPIs, comparing
  against the immediately preceding period of equal length.
- Invoicing Status (to-invoice vs. already-invoiced), Lost Pipeline
  (cancelled-quotation revenue trend), and Open Quotation Aging
  (0-7/8-30/31-90/90+ day buckets) cards.
- Full Arabic (ar_001) and Bosnian (bs_BA) translations, covering all
  86 translatable strings including JS-only labels (date-range options,
  card show/hide list) and backend-generated labels (aging buckets).

### Changed
- Removed duplicate/redundant cards (Customer Retention Rate,
  cumulative-revenue chart) that overlapped with existing metrics.
- Manifest credits Inovado D.o.o., Mirsad Selimovic, and Techman Solutions
  alongside the original author, linking inovado.ba and techman.qa.
